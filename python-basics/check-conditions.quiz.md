# Conditions — Check

## Q1 · What does the following code print?

```python
x = 10
if x > 5:
    print("A")
else:
    print("B")
```

- [x] A
- [ ] B
- [ ] AB
- [ ] Nothing

> Since `10 > 5` is `True`, the `if` block runs and prints `"A"`.

## Q2 · Which keyword adds an alternative condition in an `if` chain?

- [ ] else if
- [x] elif
- [ ] elseif
- [ ] otherwise

> Python uses `elif` (short for "else if") for additional conditions.
